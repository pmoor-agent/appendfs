# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability, flaw in cryptographic integrity, or potential data-loss bug in AppendFS, please **do not report it in a public issue**.

Instead, please report it via [GitHub's Private Vulnerability Reporting](https://github.com/pmoor/appendfs/security/advisories/new) or directly via email to **patrick@moor.ws**.

Please include:
- A description of the issue and potential security or data-durability impact
- Step-by-step instructions or proof-of-concept to reproduce the behavior
- Affected versions, platforms, or commit hashes
